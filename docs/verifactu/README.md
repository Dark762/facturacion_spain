# VERI*FACTU / RRSIF

Documentación específica de los sistemas informáticos de facturación. **No confundir** con las obligaciones de factura electrónica B2B.

- `normativa/`: leyes, reglamentos y órdenes aplicables, con vigencia verificada.
- `especificaciones/`: reglas técnicas de huellas, registros, encadenamiento, QR y remisión.
- `xsd/`: esquemas XML oficiales existentes; conservar sus versiones.
- `preguntas-frecuentes/`: preguntas y respuestas oficiales, indicando fecha.
- `ejemplos/`: ejemplos sintéticos, sin datos personales.

**Documentación preexistente:** se mantiene en esta carpeta, incluido el texto extraído de la especificación de huellas y los XSD.

Registra las fuentes oficiales en `ai/knowledge/sources.md` y comprueba su vigencia antes de modificar lógica fiscal.
